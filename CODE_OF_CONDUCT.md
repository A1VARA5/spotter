# Code of conduct

Spotter follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good faith, and keep it about the work. No harassment, no personal attacks, and no sharing anyone's private details, including real scam victims' messages. Use made up names and numbers in issues and examples, the way the demo does.

If something goes wrong, tell me privately through the repo's Security tab ("Report a vulnerability") and start the title with "Conduct". Reports are kept private, and I'll reply within 3 days. I can remove comments, issues or pull requests that break this, and block people who keep doing it.

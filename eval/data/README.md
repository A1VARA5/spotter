# Eval data

- `sms-phishing-dataset-5971.csv`: the full SMS Phishing Dataset for Machine Learning and Pattern Recognition, Sandhya Mishra and Devpriya Soni, Mendeley Data, V1, 2022, doi:10.17632/f45bkkt8pr.1, licensed CC BY 4.0 (http://creativecommons.org/licenses/by/4.0). 5,971 texts: 4,844 ham, 489 spam, 638 smishing. Unchanged from the original download.
- `sms-sample.json`: the 80 texts the 13 October eval ran on (40 smishing, 40 ham), picked from that file with a fixed seed. Results in `../results/2026-10-13.json`, write up in `../../docs/eval.md`.
